# Onboarding

Guías para empezar a trabajar en el proyecto.

## Índice

- [setup.md](./setup.md) — requisitos, clonar, instalar, levantar Postgres,
  arrancar el backend, troubleshooting
- [adding-endpoint.md](./adding-endpoint.md) — paso a paso para añadir un
  endpoint nuevo respetando todas las convenciones
- [adding-error-code.md](./adding-error-code.md) — cómo extender el
  catálogo `ErrorCode` cuando necesitas un código nuevo

## Si es tu primer día

1. Lee [CONTRIBUTING.md](../CONTRIBUTING.md)
2. Sigue [setup.md](./setup.md) para tener el backend corriendo localmente
3. Lee [conventions/code-style.md](../conventions/code-style.md) y
   [conventions/git-workflow.md](../conventions/git-workflow.md)
4. Lee [architecture/overview.md](../architecture/overview.md) para
   entender cómo está organizado el código
5. Tu primer PR puede ser trivial — sigue
   [adding-endpoint.md](./adding-endpoint.md) si vas a tocar la API
